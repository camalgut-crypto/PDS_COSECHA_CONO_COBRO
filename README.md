# PD's, Cosecha y Cono de Cobro

Seguimiento 1PD a 6PD, mora por cuota, primeros pagos por cosecha y cono de cobranza (Nicaragua).

El código se mantiene en el proyecto *Cosechas vs Cobro* (repositorio COBRO_CUENTAS) y se publica aquí con `publicar_pds.py`; los datos los sube el mismo proceso de carga al bucket privado de Supabase.
